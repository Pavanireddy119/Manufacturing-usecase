
REASON FOR FAILURE: Multiple Critical Issues

1. DATASET SIZE - CRITICAL LIMITATION
--------------------------------------------------------------------------------
   Training images: 36
   Validation images: 7
   Test images: 2
   Total: 45 images

   PROBLEM: YOLOv8n has 3.01M parameters. Training on 36 images
   causes severe OVERFITTING and UNDERFITTING.

   BENCHMARK: YOLOv8n typically requires 1000+ images minimum
   Recommended: 5000+ images for production model

   IMPACT: Model cannot learn generalizable features

2. LABEL QUALITY - HIGH IMPACT
--------------------------------------------------------------------------------
   Original dataset had:
     - 22 images with EMPTY labels (no annotations)
     - 18 classes instead of 5 target classes
     - 0 samples for 'scratch' class
     - Mix of damage types, locations, and severity as single classes

   Impact on model:
     - Mixed labels confuse the model
     - Auto-labeling errors propagate during training
     - Missing classes (scratch) prevent complete learning

3. CLASS IMBALANCE - HIGH IMPACT
--------------------------------------------------------------------------------
   Current distribution:
     - Crack: 49 annotations (44%)
     - Dent: 46 annotations (41%)
     - Paint damage: 9 annotations (8%)
     - Broken part: 7 annotations (6%)
     - Scratch: 0 annotations (0%) MISSING CLASS

   Imbalance ratio: 49:7 = 7:1 (SEVERE)

   Impact:
     - Model biased towards crack and dent
     - Poor detection of minority classes
     - Cannot predict scratch at all

4. MODEL SIZE MISMATCH - MODERATE IMPACT
--------------------------------------------------------------------------------
   Model: YOLOv8n
   Parameters: 3.01 Million
   Training samples: 36

   Parameters-to-samples ratio: 3.01M / 36 = 83,611:1 !!!

   This extreme ratio causes:
     - Severe overfitting
     - Model memorizes training data
     - Poor generalization to test data

5. TRAINING STOPPED EARLY - SYMPTOM
--------------------------------------------------------------------------------
   Configured epochs: 30
   Actual epochs: 6
   Reason: Early stopping (patience=5)

   Why it stopped:
     - Validation mAP50 not improving after 5 epochs
     - Model not learning meaningful patterns
     - Random initialization + overfitting = no improvement

================================================================================
RECOMMENDATIONS TO FIX THE MODEL
================================================================================

1. DATA COLLECTION (PRIMARY PRIORITY)
   - Collect minimum 1000-2000 images per damage type
   - Ensure balanced distribution across all 5 classes
   - MANDATORY: Add 'scratch' samples (currently 0)
   - Manual annotation or professional labeling service

2. LABEL QUALITY ASSURANCE
   - Manual review of all auto-generated labels
   - Remove/fix incorrect annotations
   - Implement inter-annotator agreement checks
   - Remove mislabeled images

3. CLASS BALANCING
   - Augment minority classes (paint_damage, broken_part)
   - Use oversampling for underrepresented damage types
   - Implement weighted loss during training
   - Ensure at least 200-300 samples per class minimum

4. TRAINING STRATEGY
   - After collecting more data, retrain for 100-200 epochs
   - Use transfer learning (ImageNet pretrained weights)
   - Implement learning rate scheduling
   - Use data augmentation (mosaic, mixup, rotation, etc.)

5. MODEL SELECTION
   - Consider smaller model (yolov8n or yolov8s)
   - With limited data, prefer simpler models
   - Once data grows to 2000+, use YOLOv8m
