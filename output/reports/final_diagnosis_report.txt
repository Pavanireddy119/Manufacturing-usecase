4. ROOT CAUSE ANALYSIS - "Why empty detections?"
================================================================================

ISSUE A: CRITICAL - MIXED CLASS STRUCTURE (60% contribution)
----------------------------------------------------------------------
- 18 classes mixing damage types (0-5), locations (6-14), and severity (15-17)
- Every bounding box has 3 identical annotations with different class IDs
  Example: same (x,y,w,h) labeled as "crack", "rear_bumper", AND "medium"
- YOLO cannot distinguish between these fundamentally different concepts
- The model learns nothing meaningful and predicts at near-random levels

ISSUE B: INSUFFICIENT TRAINING (20% contribution)
----------------------------------------------------------------------
- Only 19/100 epochs completed (early stopping triggered too early)
- mAP50 stopped at 0.083 (only slightly above random 1/18 = 0.056)
- The model hasn't learned to identify any class reliably
- With patience=15, training stopped as soon as metrics plateaued

ISSUE C: SEVERE CLASS IMBALANCE (10% contribution)
----------------------------------------------------------------------
- dent:    820 annotations (89.2% of total)
- scratch:   2 annotations (0.2% of total)
- Missing:   class 5 (other_damage) has ZERO annotations
- Model biases towards majority class, ignores rare classes

ISSUE D: ANNOTATION QUALITY / OVERLAP (10% contribution)
----------------------------------------------------------------------
- 5256 total label lines but only 1752 unique damage boxes (3x duplication)
- 302/894 images have NO damage annotations (only location/severity)
- All location and severity labels have EXACT same coordinates as damage
- This annotation structure is fundamentally incompatible with YOLOv8

    Remove from YOLO training:
    - Locations (use heuristic: centroid position => vehicle part mapping)
    - Severity (train separate classifier or use heuristic: box size ratio)

    Benefits:
    - Eliminates triplicate box confusion
    - Reduces 18-class problem to simpler 6-class problem
    - Each box now has UNIQUE semantic meaning
    - Locations can be inferred from bounding box position
    - Severity can be estimated from damage extent relative to vehicle
